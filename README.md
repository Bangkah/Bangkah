# Bangkah - Laravel Starter Kit Package

A modern Laravel starter kit that automates project scaffolding.

## Quick Start

\`\`\`bash
composer global require bangkah/bangkah
bangkah create
\`\`\`

## Features

- Pre-configured Laravel 12 project
- Docker setup (Nginx, PHP, MySQL, Redis)
- Vite + npm build tools
- Best practices included
- Professional templates

## Requirements

- PHP 8.2+
- Composer 2.0+
- Node.js 18+ (optional)
- Docker (optional)
